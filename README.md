# Родословная — семейное древо онлайн

Веб-приложение для составления родословной: интерактивное древо, подробные сведения о каждом человеке, фото и документы,
источники, росписи, статистика и проверка данных. Работает в браузере и без интернета (PWA), готово к подключению
сервера на GraphQL.

**Онлайн-версия:** https://shevtsov-max.github.io/test-ii/ — обновляется после каждого изменения в `main`.

## Запуск

```bash
npm ci
npm run dev        # http://localhost:5173
npm test           # модульные тесты (vitest)
npm run build      # иконки + сборка в dist/ (статические файлы для любого хостинга)
npm run preview    # посмотреть собранную версию
```

Нужен Node.js 20+. Настройки сборки — переменные окружения, см. [`.env.example`](.env.example).

## Возможности

**Древо**
- Четыре вида: *Древо* (предки сверху, потомки снизу), *Родословная* (компактная схема предков), *Веер*, *Лента времени*.
- Охват древа, как в «Древе Жизни»: прямые предки и потомки · прямая родня с братьями и сёстрами · кровные
  родственники · все родственники (включая родню супругов, раскладка по поколениям с минимизацией пересечений).
- Нестандартные случаи: несколько браков, сводные братья и сёстры, приёмные/усыновлённые/опекаемые дети и отчимы
  (пунктир), несколько семей-родителей у ребёнка, браки между родственниками и «схлопывание» предков, помолвка и
  гражданский брак, развод и вдовство.
- Подпись родства над каждой карточкой («Двоюродная бабушка», «Муж свояченицы») и цепочка «Как связаны?».
- Добавление родственников прямо на схеме («+» у карточки), контекстное меню, горячие клавиши F3/F4/F5/F8,
  история центра (Alt+← / Alt+→), мини-карта, подсветка линий, уровни детализации при отдалении.
- Экспорт схемы в SVG, PNG и на печать; раскраска по полу, роду или поколениям.

**Сведения о человеке**
- ФИО с девичьей фамилией и отчеством (подставляется по имени отца), прозвище, титул, порядковый номер
  («Николай II»), род, место жительства, занятие, контакты, биография, заметки, свои дополнительные поля.
- Даты с точностью: «около 1850», «до/после», «между 1880 и 1885», старый стиль («6 (18) мая 1868»), текст.
- События жизни, справочник мест с иерархией, источники со ссылками и оценкой достоверности, фото и документы
  (один файл — несколько людей), избранное, приватность.

**Разделы древа:** обзор, персоны (таблица с настраиваемыми столбцами и фильтрами как в «Древе Жизни», CSV, печать),
профиль персоны, события (летопись по десятилетиям), места, медиа, источники, роды, росписи (поколенная и восходящая
по Соса), статистика, проверка данных (противоречия в датах, дубликаты с объединением, незаполненные записи),
настройки древа (поля, доступ, импорт/экспорт, удаление).

**Сайт:** главная страница, вход, регистрация (гостевые древа переходят в учётную запись), восстановление пароля,
подтверждение почты, мастер «Новое древо», учётная запись (профиль, пароль, тема, версия и обновления приложения,
хранилище), справка, политика конфиденциальности, условия использования, страница 404.

**PWA:** установка на телефон и компьютер, работа офлайн, обновление по кнопке «Обновить» (с проверкой новых версий
каждые 30 минут и вручную), окно «Что нового» после обновления.

**Данные:** резервная копия JSON с фото, GEDCOM 5.5.1 (импорт/экспорт, перенос из «Древа Жизни», MyHeritage,
Ancestry), автоматический перенос древа из прежней версии приложения (localStorage).

## Режимы работы с данными

| Режим | Как включить | Где данные |
|---|---|---|
| `local` (по умолчанию) | ничего не нужно | IndexedDB браузера: локальные учётные записи (PBKDF2), гостевой режим, файлы |
| `graphql` | `VITE_API_MODE=graphql`, `VITE_GRAPHQL_URL=…` | сервер по контракту [`docs/api/schema.graphql`](docs/api/schema.graphql) |

Интерфейс приложения одинаков в обоих режимах: страницы и сторы обращаются только к `api` из `src/api/index.js`.

## Структура

Подробно — в [`docs/architecture.md`](docs/architecture.md).

```
src/
  domain/        чистая логика без Vue: модель, даты, имена, граф семьи, родство, GEDCOM, росписи, проверка
    layout/      алгоритмы раскладки древа (песочные часы, слоистая, родословная, веер, лента)
  api/           слой данных: local (IndexedDB) и graphql — один интерфейс
  stores/        Pinia: auth, trees (список), tree (открытое древо, история, сохранение), prefs, ui, pwa
  app/           конфигурация, маршруты, перенос старых данных, список изменений, горячие клавиши
  layouts/       каркасы страниц: публичный, вход, приложение, древо
  pages/         страницы по разделам: public, auth, app, tree
  components/    chart (отрисовка древа), person, dialogs, inputs, media, stats, workspace, auth, ui
  composables/   переиспользуемая логика компонентов
  styles/        дизайн-токены (светлая и тёмная темы) и общие стили
  data/          примеры древ (Романовы, Орловы) и заготовки
tests/           модульные тесты доменной логики и раскладок
docs/            архитектура и GraphQL-схема
scripts/         генерация иконок, портретов для примера и PWA-иконок
```

## Скрипты

- `scripts/gen-icons.mjs` — собирает в `src/icons.generated.js` только используемые иконки Material Symbols
  (`sym_r_*`); запускается сам перед `dev` и `build`.
- `scripts/gen-portraits.mjs` — SVG-портреты для примера «Романовы» (`public/photos/`).
- `scripts/gen-pwa-icons.mjs` — PNG-иконки приложения из `public/favicon.svg` (нужен Playwright, запускается вручную).
