# Родословная — семейное древо на Vue 3 + Quasar

Полнофункциональный редактор семейного древа в духе MyHeritage: семейный вид с добавлением
родственников прямо на холсте, профили, факты, фото, отношения, импорт/экспорт GEDCOM.

## Онлайн-версия

https://shevtsov-max.github.io/test-ii/ — автоматически обновляется после каждого изменения в `main`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ (статические файлы, можно положить на любой хостинг)
npm run preview    # посмотреть собранную версию
```

Нужен Node.js 20+.

## Возможности

**Семейное древо (главный вид)**
- Раскладка «песочные часы» вокруг центральной персоны: предки вверх, потомки вниз, братья/сёстры,
  другие партнёры родителей и сводные братья/сёстры. Контурная упаковка без пересечений.
- Карточки с фото/силуэтом, годами жизни, «Это Вы», родством; цвет по полу.
- Кнопка «+» под карточкой → оверлей: добавить отца, мать, брата, сестру, партнёра, сына, дочь
  (на телефоне — нижняя панель).
- Пунктирные подсказки «Добавить отца / мать» над прямыми предками.
- Значок на линии пары → редактирование отношений (брак, развод, помолвка, даты, общие дети).
- Стрелки на карточке — есть скрытые предки/потомки, клик переводит центр.
- Перетаскивание, масштаб колесом/щипком, «показать всё», домой, полный экран, плавные анимации
  при смене центра.
- Поиск персоны, выбор количества поколений, настройки отображения, тёмная тема.

**Редактирование**
- Форма добавления/изменения: пол, имя, фамилия, отчество (подставляется автоматически по имени
  отца), девичья фамилия, звание, статус, даты с точностью (точно/около/до/после/между), места с
  автодополнением, жив/умер, e‑mail, выбор второго родителя / семьи для сводных.
- Режим «Выбрать из древа» — связать уже существующих людей.
- Профиль с вкладками: обзор и хронология, факты (образование, профессия, служба, награды…),
  биография, фотогалерея (главное фото, подписи, просмотр), родственники (изменить/удалить связи).
- Удаление персоны, отвязка от родителей, разрыв пары.
- Отмена/повтор (Ctrl+Z / Ctrl+Shift+Z), автосохранение в localStorage.

**Другие виды:** родословная (предки слева направо), веерная диаграмма, таблица со
фильтрами и экспортом CSV.

**Данные:** резервная копия JSON (с фото), экспорт и импорт GEDCOM 5.5.1 — можно перенести
древо из MyHeritage («Управление древом» → «Экспорт в GEDCOM»).

## Структура

```
src/
  types.js                  модель данных (JSDoc-typedef): Person, Family, GDate…
  stores/tree.js            Pinia: данные, история, все операции над древом
  stores/ui.js              состояние диалогов
  utils/layout.js           алгоритм раскладки семейного вида
  utils/graph.js            родители/дети/братья, расчёт родства по-русски
  utils/gedcom.js           импорт/экспорт GEDCOM
  utils/names.js            отчества и род фамилий
  components/tree/          холст, карточка, оверлей «+», элементы управления
  components/views/         семейный вид, родословная, веер, список
  components/dialogs/       формы персоны, профиль, отношения, факты, данные, справка
  components/layout/        шапка и панель персоны
```

Иконки — Material Symbols в виде SVG (скрипт `scripts/gen-icons.mjs` собирает только
используемые, запускается автоматически перед `dev`/`build`).

Для подключения бэкенда достаточно заменить сохранение в `stores/tree.js` (watch → localStorage)
на запросы к API — все изменения проходят через действия стора.
